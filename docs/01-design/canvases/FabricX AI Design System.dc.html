Selvage edge

addendum · 05

A 3px stripe on the left rim of a card or table row, carrying one status colour — the finished edge of a fabric roll. The selvage replaces status-tinted backgrounds entirely: the surface stays neutral, the edge carries the verdict, and a wall of rows stays readable because only 3px of it is coloured.

Thread rule

addendum · 06

A dashed divider of 2px strokes repeating at 115° — the counter-thread of the X mark, where the slash rule takes the 34° warp. It closes a page header and separates sections. Two variants only: accent under the header, muted between sections.

Accent variant — under a page header

Same geometry in border-default, 7px tall. Use it wherever a 1px horizontal rule would otherwise appear inside a card. Repeatable, unlike the accent variant.
115°, not 34°
The slash rule and the progress bar own the 34° warp. The thread rule takes the crossing weft so the two never read as the same element.
Never a border
It is a spanning divider, not an outline. Never wrap a container, never run vertically, never fill as progress.
One accent per page
Two amber thread rules in one viewport breaks the amber rule. Demote the second to muted.

Bengali type

addendum · bn

Anek Bangla is the Bengali companion to Plus Jakarta Sans — a low-contrast humanist face with the same optical size, so the two sit at identical px values without one looking set larger. Every string in the product exists in both; the layout is built for the longer one.

Bengali digits

On for dates, counts and durations inside Bengali prose. Off — and always off — for identifiers, money, quantities in tables and anything in mono: PO-88203 never becomes পিও-৮৮২০৩. Never mix scripts inside one token.
Three hard rules
No tracking on Bengali — the −0.02em display tracking is Latin-only; matra clusters break at negative values.
No 700 headings — Anek Bangla's 600 already carries the weight of Jakarta's 700. 400 / 500 / 600, nothing above.
No uppercase transform — Bengali has no case. Eyebrow labels stay mono Latin in both languages.
